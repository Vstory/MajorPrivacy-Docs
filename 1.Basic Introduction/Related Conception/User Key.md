User Key is the core mechanism that MajorPrivacy uses to ensure that configurations are made by the user and have not been tampered with.  
It is essentially underpinned by asymmetric encryption. When a user sets a User Key, MajorPrivacy generates a public-private key pair. The public key is made public and can be used to decrypt configuration files; the private key is encrypted using a key derived from the user's password, which ensures that configuration files can only be legally modified when the user explicitly enters their password.  
The User Key is also used for the integrity control exemption built into MajorPrivacy. When a Program Rule is specified to apply only, or applied to a program that includes a User Key, the user can sign the binary. This process is carried out after the user decrypts the private part of the User Key with their password, and then signs the program's certificate or hash.  
The User Key displayed on the title bar of the MajorPrivacy window is the digest of the public key portion and does not involve any confidential parts.
