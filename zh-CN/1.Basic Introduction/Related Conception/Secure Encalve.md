# 安全飞地

安全飞地是 MajorPrivacy 进程安全模型中的一个关键概念，旨在通过多层防护将其与外部不受信任的应用程序明确隔离。
您可以在 <a href="../Panel/Secure Enclave.md">安全飞地面板</a> 中配置相关设置。

飞地本身通常包含以下配置区块：
1. 飞地名称
2. 飞地注释
3. 代码完整性预设
4. 进程创建处理
5. 其它选项

下面，我们将详细解释配置区块 3、4 和 5。

代码完整性预设由以下配置组成：
 - **必需签名**：飞地内运行的所有应用程序都必须满足此配置项所指定的数字签名级别。对于发起进程，如果不满足要求，将被"弹出"飞地。对于子进程，将应用"进程创建处理"中的设置。如果启用了映像加载保护，则应用程序加载的模块也将受到此限制。
   - **无签名**：任何程序/模块都满足要求。
   - **任意签名（未知根）**：带有数字签名的程序/模块满足要求，但证书的根颁发者无需受操作系统信任。
   - **用户签名 + Microsoft 信任签名（代码根）**：如果程序/模块具有受 `ci.dll`（不受用户态"受信任的根证书颁发机构"存储影响）信任的数字签名，或具有用户签名，则满足要求。
   - **用户签名 + Microsoft/杀毒软件签名**：如果程序/模块的数字签名证书由 Microsoft 直接颁发，或受 Microsoft 认可的杀毒软件信任，或具有用户签名，则满足要求。
   - **仅用户签名**：如果程序/模块具有用户签名的数字签名，则满足要求。
 - **映像加载保护**：勾选后，如果飞地内的应用程序尝试显式加载任何模块，而该模块不满足要求，其加载将被阻止。

进程创建处理由以下配置组成：
 - **受信任时**：如果发起进程创建的子进程满足签名要求，则可执行以下操作：
   - **允许执行**：继续在飞地内执行。
   - **阻止执行**：阻止其在飞地内外执行。
   - **弹出**：将其移出飞地范围，使其不再受飞地保护。
 - **不受信任时**：如果发起进程创建的子进程不满足签名要求，则可执行以下操作：
   - **允许执行**：继续在飞地内执行。
   - **阻止执行**：阻止其在飞地内外执行。
   - **弹出**：将其移出飞地范围，使其不再受飞地保护。

其它选项由以下配置组成：
 - **UIPI 级别**：标准用户帐户下运行的进程级别通常为"中"，而提升权限的进程通常为"中+"或"高"。级别低于所选级别的程序将无法通过窗口消息模拟用户对飞地内进程窗口的操作，也无法使用屏幕截图以外的方法获取窗口信息。
 - **防止终止**：防止飞地内运行的进程被终止。
 - **允许调试**：允许调试飞地内的进程。这是一种极其不安全的行为，因为它将允许任何提升权限的进程完全访问飞地内进程的所有信息，包括存储的用户密码。虽然在测试阶段，MajorPrivacy 曾为方便自身调试而采用此配置，但用户在日常使用中绝对不应启用此选项。

除非启用了"允许调试"选项，否则 MajorPrivacy 将阻止飞地外的任何进程（PPL 进程除外）以侵入性权限（如读取内存）访问飞地内运行的进程。
